# Nilset 友链列表
# 一行一个友链；空行会被忽略；# 开头是注释。
#
# 格式：
# 链接 | 显示名 | 一句话介绍 | 图标路径
# 链接可以带 https://，也可以只写域名；只写域名时自动使用 https。
#
# 后三项都可以省略。
# 显示名省略时使用域名。
# 图标路径通常不用填；脚本会自动尝试获取网站图标并缓存到 images/friends/。
# 如果想手动指定，可写：images/friends/example.png
#
# 示例：
# https://www.idadwind.com | idadwind | 朋友的博客
# koch2333.cn | koch2333

idadwind.com | idadwind
koch2333.cn | koch2333
